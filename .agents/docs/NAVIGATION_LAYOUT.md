# Navigation and layout terminology

## Timeline controls

The Gantt display-preference control is labeled **Timeline Settings**. It
controls calendar scale, grid, dependency visibility, and critical-path display;
the label describes the control's actual scope.

## Planning workspace

The header action is labeled **Planning Intelligence** and uses a line-chart
icon. It opens the existing workspace containing Forecast, History, Scenarios,
Baselines, and Proposals. This wording distinguishes analytical planning
intelligence from the Timeline itself, which remains the primary execution
workspace.

This terminology follows common project-management usage: baselines are
reference plans compared against current progress, while scenarios and
forecasts describe alternatives and expected outcomes. See [Microsoft's
baseline guidance](https://support.microsoft.com/en-us/project/create-or-update-a-baseline-or-an-interim-plan-in-project-desktop),
[Forecast's baseline guidance](https://support.forecast.app/hc/en-us/articles/4977167479185-Setting-and-reviewing-project-Baseline),
and [Project Commander's planning terminology](https://www.projectcommander.app/).

## Task labels

Task labels are editable user-authored metadata. Existing labels can be edited
or deleted, and new label values can be added from the task edit form. A global
label-management page is intentionally outside this task's scope.
